# 📚 AluraBooks 2

<p align="justify">
Este projeto consiste em uma página responsiva da Alura Books, desenvolvida com o objetivo de apresentar um catálogo de livros relacionados à tecnologia e programação. A plataforma permite explorar diferentes obras das áreas de Front-end, Back-end e Dados, exibindo informações como título, autor, preço, categoria e disponibilidade. Além disso, conta com funcionalidades interativas de filtragem por categoria e ordenação por preço, proporcionando uma experiência prática e organizada na busca pelos livros disponíveis.

### ✔️ Funcionalidades

- 📱 **Design responsivo**: Interface adaptada para smartphones, tablets e computadores, garantindo uma boa experiência em diferentes tamanhos de tela.
- 🎨 **Catálogo de livros**: Exibição de livros relacionados às áreas de Front-end, Back-end e Dados, apresentando capas, títulos, autores e preços.
- 🔎 **Filtragem por categoria**: Permite visualizar livros de Front-end, Back-end ou Dados de acordo com a categoria selecionada.
- 📚 **Livros disponíveis**: Exibe todos os livros cadastrados no catálogo, permitindo visualizar novamente todas as categorias.
- 💰 **Ordenação por preço**: Organiza os livros disponíveis de acordo com seus valores, facilitando a visualização dos preços.
- 📦 **Verificação de disponibilidade**: Permite identificar quais livros estão disponíveis ou indisponíveis para compra.
- 🔄 **Manipulação dinâmica dos livros**: Utilização de JavaScript para filtrar, ordenar e atualizar os livros exibidos na página.
- 🌐 **Consumo de API**: Utilização de dados obtidos por meio de uma API para carregar as informações dos livros dinamicamente.
